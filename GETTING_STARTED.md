# С чего начать — запуск и использование NormaCAD AI

Это пошаговая инструкция, чтобы запустить проект у себя и понять, как он работает.
Рассчитана на то, что ты впервые видишь этот код. Если что-то не пойдёт — пиши, разберёмся.

---

## 0. Что это такое (коротко)

**NormaCAD AI** — веб-сервис предварительного нормоконтроля чертежей по ГОСТ/ЕСКД.
Загружаешь чертёж (DXF или вектор-PDF) → сервис проверяет оформление (формат листа, масштаб,
высоту шрифта, толщину линий, основную надпись) → показывает отчёт: где что не по ГОСТ,
как исправить, с цитатой пункта стандарта, и подсвечивает места прямо на чертеже.

Важно: **числа считает обычный код, а не нейросеть** — поэтому нет «галлюцинаций».
ИИ используется только в чате-справочнике по ГОСТ (и в будущем — для распознавания сканов).

---

## 1. Что нужно установить заранее

- **Python 3.12** — https://www.python.org/downloads/ (при установке поставь галочку **Add Python to PATH**).
- **Git** — https://git-scm.com/download/win (нужен, чтобы скачать проект; можно и скачать ZIP-кнопкой на GitHub).

Проверь, что Python виден — открой PowerShell и набери:
```powershell
python --version
```
Должно показать `Python 3.12.x`.

---

## 2. Скачать проект

Вариант А (через git) — открой PowerShell в папке, куда хочешь положить проект, и выполни:
```powershell
git clone https://github.com/zghchjjhcxbeen-collab/normacad-ai.git
cd normacad-ai
```

Вариант Б (без git) — на странице репозитория нажми зелёную кнопку **Code → Download ZIP**,
распакуй, и зайди в папку проекта через PowerShell (`cd путь\к\папке`).

---

## 3. Установить зависимости (один раз)

В папке проекта выполни по очереди:
```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
Это создаст изолированное окружение `.venv` и поставит все библиотеки. Займёт пару минут.

---

## 4. Сгенерировать тестовые чертежи и проверить, что всё работает

```powershell
$env:PYTHONUTF8 = '1'
.\.venv\Scripts\python.exe scripts\make_bootstrap_dxf.py
.\.venv\Scripts\python.exe scripts\make_demo_files.py
.\.venv\Scripts\python.exe -m pytest -q
```
В конце должно быть **`52 passed`** — значит ядро и веб-слой исправны.

---

## 5. Запустить сайт

```powershell
$env:PYTHONUTF8 = '1'
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```
Открой в браузере **http://127.0.0.1:8000**.

Зарегистрируйся (кнопка «Регистрация») — при регистрации можно выбрать тип: обычный
пользователь / бюро / предприятие (это влияет на приватность чата, см. п.7).
Окно не закрывай, пока пользуешься сайтом. Остановить сервер — `Ctrl+C` в этом окне.

---

## 6. Проверить чертёж (главная функция)

1. На сайте нажми **«Проверить»** (или перетащи файл на страницу).
2. Загрузи `data\demo\demo_dirty.dxf` — это «грязный» чертёж с заложенными ошибками.
   Через секунду откроется **отчёт**: 5 замечаний (формат, масштаб, шрифт, штамп, линия),
   у каждого — «как исправить» и цитата ГОСТ, а сам чертёж нарисован с **подсветкой** мест.
3. Загрузи `data\demo\demo_clean.dxf` — корректный чертёж → **0 замечаний** (так и должно быть:
   на верном чертеже сервис молчит).
4. Можно загружать свои **DXF** и **вектор-PDF** (born-digital, не скан).

**Обратная связь в отчёте:** у каждого замечания есть кнопки **«Подтвердить» / «Ложное»**, а
внизу — форма «добавить замечание, которое ИИ пропустил». Это для нормоконтролёра: так
система собирает данные о своей точности.

---

## 7. ИИ-чат-справочник по ГОСТ

На сайте есть **«Чат»** — можно спросить про ГОСТ (например, «минимальная высота шрифта по 2.304?»).
Как он отвечает, зависит от настройки `CHAT_BACKEND`:

- **по умолчанию (`stub`)** — без нейросети: находит нужный стандарт в базе ГОСТ и показывает
  выдержку. Работает сразу, офлайн, ничего настраивать не надо.
- **`local`** — локальная нейросеть (Ollama) на твоём компьютере. Приватно, данные никуда не уходят.
  Как поднять — в [docs/local-chat-setup.md](docs/local-chat-setup.md).
- **`claude`** — облачная модель (нужен API-ключ). Только для обычных пользователей;
  бюро/предприятиям облако недоступно на уровне кода (приватность).

Чтобы чат и цитаты ГОСТ под замечаниями были полноценными, нужна **база ГОСТов** — это отдельная
папка с текстами стандартов, путь к ней задаётся переменной `GOST_DB_DIR` (см. `.env.example`).
Без неё проверка чертежей работает полностью, а чат отвечает ограниченно. Базу скину отдельно.

---

## 8. Настройки (необязательно)

Все настройки — через файл `.env` (скопируй из `.env.example` и поправь). У всего есть значения
по умолчанию, так что для первого запуска `.env` можно не трогать.

## 9. Где что лежит (карта проекта)

```
app/         весь код сайта и движка проверок (rules — правила, parsing — чтение DXF/PDF)
scripts/     генерация тест-файлов, калибровка, демо, диагностика
docs/        доп. инструкции (демо-сценарий, локальная модель, спайк по DWG)
data/demo/   готовые демо-чертежи (чистый и с ошибками)
tests/       автотесты (pytest)
PLAN.md      полный план проекта (что сделано и что впереди)
README.md    краткое описание
```

## Если что-то не работает

- `python` не распознаётся → Python не в PATH, переустанови с галочкой «Add to PATH».
- Кириллица в консоли кракозябрами → выполни `$env:PYTHONUTF8 = '1'` перед запуском.
- Порт 8000 занят → запусти на другом: `--port 8001` и открой `http://127.0.0.1:8001`.
- Любая ошибка — пришли мне текст из консоли, разберёмся.
