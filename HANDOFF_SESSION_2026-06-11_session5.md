## 1. Калибровка на реальных файлах (важное наблюдение трека A)

Прогнал `scripts/calibrate_corpus.py` по `C:\Users\elisei\OneDrive\Desktop\Новая папка (3)` (4 файла):
- `чертёж 1.dxf` (КОМПАС, A3): **0 critical/major**, 1 INFO (штамп без тегов) — как и в прошлой калибровке, регресс цел.
- `чертёж 1.pdf`, `чертёж 2.pdf`: **`raster_pdf`** (нет текстового слоя — это СКАНЫ) → только 1 INFO «загрузите вектор-PDF/DXF», без ложных critical. Precision-first работает.
- презентация .pdf (не чертёж): `vector_pdf` 677×381 → major 2.301 + minor 2.304. Факты верны, но это не чертёж.

**Вывод для владельца:** половина реальных PDF оказалась сканами без текстового слоя. По таким точные офлайн-проверки невозможны — нужен **DXF или born-digital вектор-PDF**, иначе растровый тракт (Этап 5, OCR). Когда соберёшь корпус (30–50 файлов) — проси именно DXF/вектор-PDF, а сканы складывай отдельно (под будущий OCR). Запусти: `calibrate_corpus.py "<папка>" --json out.json` и пришли расхождения.

**Робастность-замечание:** у движка нет гейта «а это вообще чертёж?». Не-чертёж (презентация) даёт технически-верные, но бессмысленные замечания. Возможный будущий фильтр: «есть рамка+штамп → считаем чертежом, иначе INFO». Не критично сейчас.

## 5. Новые грабли (не повторять)

- **№14:** PowerShell `Start-Job` для сервера живёт только внутри ОДНОГО вызова PowerShell-инструмента и умирает с ним → health сразу после старта проходит, а в следующем вызове «соединение отклонено». Для долгоживущего сервера использовать harness-level фоновый запуск (`run_in_background: true`), а не `Start-Job`.
- **№15:** к аккаунту подключены ДВА браузера (macOS + Windows) → живой скриншот через Claude-in-Chrome требует ручного выбора браузера (AskUserQuestion). Для проверки рендера без браузера — бить по запущенному серверу через `httpx` (логин → CSRF → нужный фрагмент) во временном `.py` (грабли №11), потом удалить.
- Тесты с записью в БД — на ВРЕМЕННОЙ БД через `app.dependency_overrides` (get_db + get_current_user), сидинг/проверки отдельным async-движком на том же файле (NullPool, свой event loop), утверждения по HTTP-ответам и по БД. Шаблон — в `tests/test_feedback.py`. Грабли №10 (не трогать реальный `normacad.db`) соблюдены.
