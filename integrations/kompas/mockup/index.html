NormaCAD.PRO для КОМПАС-3D: макет окна, задача #47

Макет на согласование. Окно собирается штатными контролами WinForms .NET 4 без сторонних библиотек: Label, LinkLabel, Button, TextBox, ComboBox, CheckBox, ProgressBar, GroupBox, Panel, FlowLayoutPanel, TableLayoutPanel. Тексты замечаний и обозначения в макете примерные.

Главное окно 520×600 (сейчас 640): при масштабе 150% на экране 1920×1080 окно целиком помещается над панелью задач. На меньшем экране окно ужимается по рабочей области, а списки прокручиваются. Раскладка — TableLayoutPanel и FlowLayoutPanel с AutoSize, без абсолютных координат. Поток окна объявляется DPI-aware (SetThreadDpiAwarenessContext), иначе при 150% Windows растягивает окно картинкой и текст размывается.

Ход проверки и очередь — поля ответа GET /api/drawings/jobs/{id}: stages, queue_ahead, eta_seconds, heavy_load, pages_done и pages_total. Названия этапов и фразы — как на странице проверки сайта. Отменить идущую проверку сервер не умеет, поэтому кнопки «Отменить» нет. Аккаунт и лимит — поля GET /api/users/me/access: plan_label, access_until, remaining, checks_limit, window_hours, reset_at.

Карточка отчёта — Panel с цветной полосой (Panel, Dock = Left) во FlowLayoutPanel с прокруткой. Поля карточки — те же, что в отчёте сервера: severity, page, title, standard, detail, fixes. Источник «ПК» — замечания по основной надписи без ИИ (#45). «Пояснение» показывает и скрывает detail. «Проверить снова» заново выгружает активный документ с текущими правками: это новая проверка, она учитывается в лимите.

Кнопки сбоев (фразы — как в коде расширения по #46, тексты лимита — как присылает сервер):

  • «Повторить» — новая попытка;
  • «Настройки прокси» — окно расширения: адрес, логин и пароль прокси (пароль под DPAPI), пусто — системный прокси; там же ссылка «Настройки прокси Windows»;
  • «Изменить адрес сервера» — окно входа с полем «Сервер»;
  • «Связаться с командой» — страница «Контакты» на сайте;
  • «Получить результат» — повторный опрос задания;
  • «Скачать новую версию» — адрес из ответа сервера (KOMPAS_DOWNLOAD_URL), без него — сайт.

Вход истёк или закрыт на сайте (ответ 401) — сразу окно входа (состояние 1).

«Журнал для поддержки» открывает папку с журналом; пароли и токены туда не пишутся. Параметр ?only=<имя> показывает одну рамку.
